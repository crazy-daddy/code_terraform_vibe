## Where phase 8 left things

- Power `trim` re-evaluates after the one-shot cut: `#trimPass` keeps the per-window peak `consumed` once `done`, and every `reevalTicks` (`trimReevalTicks()`: null = `warmupTicks`, 0 = off, else whole ticks; validated in the constructor before the archive seeds and any group's setup) `#trimReeval` restarts stopped generators (`script.run` through `sim.h.command`, highest-rated first from `t.pool[subnet]`) until the kept rating covers `peak × margin`. A refused restart (`result.ok !== true`) is warned and dropped from the pool, never counted as kept. Restart only, never a second stop (an oscillating kept set would drag the ghosts count with it). Restarted slots leave `t.stopped` and the ghosts (unless the scenario's `ghosts` override is set). `summary.standins.trim` gained `restarted` and `evals`; one `standins: power trim <subnet>: window peak ... restarted N (...)` line per restarting re-evaluation.
- A/B on 1220 (phase 7 pair, `--hours 0.33 --report-every 5`, default log levels): 4 turbines stop at the trim, 3 come back in the first window (4.7 kW), the last at 5.1 kW; from 0.25 h the grid equals the real run's 7,004 W, the bank ends 0.5 kWh above real, atmosphere and credits identical, ghosts 0 at the end, so no speed-up left on this save. `trim` is a safe cut that undoes itself when the load arrives.
- Tests: `test/standins.test.mjs` +3 (restart on a later peak with `stops` re-checked, `reevalTicks: 0` plus the throw before any side effect in a `default: "off"` scenario, a refused restart dropped with the `ghosts` override kept); `scenario.test.mjs` default params; 55 green with `node --test "devtools/simulation/headless/test/*.test.mjs"`.
- Docs: `standins.md` (`trim` row, phase table row 8, design note), `scenarios.md` (summary field, console line), `ab_results.md` "Phase 8". TODO's headless block has the phase 8 line.
- `subnet.consumed` is demand, not served load: on 1220 it exceeds `generated` while the trimmed grid is capped (6,716 W against 6,572 W). The re-evaluation relies on that; if a game update changes it to the served load, a capped grid never raises the need and the restarts stop.
- Outputs in `out/ab8_*` (never commit `out/`).

Pitfalls that still apply: `pass(t)` counts from the run's start, archive ages use `state.tickCount`; `--only-scripts` pins `keep` and a stand-in skips kept slots; validate params for value before any side effect (the constructor, not `#setup`, for anything that must precede the archive seeds); the watcher does not cover `devtools/`; a group that is off or stood in has a boundary (`GROUPS[g].produces` / `consumes`) and the A/B gaps come from there first, name them in ab_results.md rather than tuning the stand-in; `final_save.json` is the raw state (no `state` wrapper) and is UTF-8; `run.mjs --hours` and `summary` hours are clock hours (36,000 ticks), planet-hours (250 ticks) are the construction and day-cycle unit; a generator's `generated` share is demand, not capacity; two background runs in parallel keep wall times comparable only within the pair.
