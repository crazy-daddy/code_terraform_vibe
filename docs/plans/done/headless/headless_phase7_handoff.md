## Where phase 6 left things

- Both modes are state writes in `Standins.beforeTick()` (`standins.mjs` `#topupPass`, `#instantPass`): the PowerSystem reads the batteries' `data.charge` fresh each tick and the ConstructionSystem derives a job's progress from `endsAtGameTime`. `instant` also needs one simworker patch, `INSTANT_PATTERN` in `anchors.mjs` (feature `instantBuild`, `node devtools/simulation/headless/anchors.mjs` prints its count): the builder's construction command yields a scheduler `wait` for the whole remaining build time, so without the patch the job finished in the state while the Pioneer slept (first 0393 run: same finish tick as real). The patch makes the wait 2 ticks while `globalThis.__ctInstantBuild` is set (the mode sets it at setup; one Sim per process).
- New group `construction` (no machine type; `off` under `default: "off"` is skipped silently in `#setup`, since there is nothing to stop or stub). `MODES.power.topup`, `MODES.construction.instant`, both without params. `summary.standins.topup = {batteries, addedWh}`, `summary.standins.instant = {jobs, savedS, wait}` (clock seconds, the unit of `planet.clock.elapsedTime`; a build of `constructionGameHours` h lasts `h × dayCycleDuration / 24` s, so 25 s per planet-hour).
- Game facts read 2026-10-14 (decompiled worker): `PowerSystem.tick` filters `t.batteries.filter(e => e.powered)` (truthy, so an unset `powered` is ignored, matched in `#topupPass`), sums `data.charge`, clamps to summed `data.capacity ?? config.power.batteryCapacity` (500) and writes the fill fraction back. `ConstructionSystem` is minified `SA` (find it by the `ConstructionSystem failed` log line); `progress = 1 - max(0, endsAtGameTime - elapsedTime) / duration`, completion at 1; the builder's start command consumes the kit once (`materialConsumed`) and sets `endsAtGameTime`. Kind durations: `lA` table (pipe, power_line, deconstruct 0.05 h; bridges, upgrade 0.5 h; outpost 4 h; machines 1-4 h via the kit's `constructionGameHours`).
- A/B: `topup` on 0142 holds the home bank at 2,500 Wh, the Power Guard never sheds, heat +4.6 % (boundary, named in ab_results.md). `instant` on 0262 changes nothing: the jobs there are pipe and line segments (1.25 s each), finished within the builder's poll cadence in both runs. On 0393 (one active outpost job, 79 s left) the patched run finishes it 790 ticks earlier with the atmosphere unchanged; the credit gap (−4,400 cr) is eight more Pioneer upgrades downstream of the earlier outpost.
- Tests: `test/standins.test.mjs` +3 (topup, instant, construction off under default off), `patch_scale.test.mjs` +1 (the instant wait pattern on a synthetic snippet), `anchors.test.mjs` asserts the wait anchor once on the real worker; 49 green with `node --test "devtools/simulation/headless/test/*.test.mjs"`.
- Docs: `standins.md` (group row, two Mode rows, phase table row 6, design note), `scenarios.md` (summary fields), `stub_tests.md` §10b (mode list) and §10c step 4 (anchor count), `anchors.md` (`instantBuild` row). ## Open (optional)

1. Power `trim` with an effect: needs a save with surplus turbines or oil generators (check `peak × margin / perGenerator` against the count first; the 20261008 run's `1211`-`1225` saves have the most generators).
2. `instant` skips only the on-site build time. The builder's drive, kit loading and start stay real; a mode that also places pending blueprints (kit from the Inventory, no builder) would be a different boundary (the logistics group's "construction" output) and would need the game's own placement command, not a state write.
3. `topup` fills every battery on the planet. A per-subnet or per-outpost parameter is a small change if a target needs one grid real.

Pitfalls that still apply: `pass(t)` counts from the run's start, archive ages use `state.tickCount`; `--only-scripts` pins `keep` and a stand-in skips kept slots; validate params for value before any side effect; the watcher does not cover `devtools/`; a group that is off or stood in has a boundary (`GROUPS[g].produces` / `consumes`) and the A/B gaps come from there first, name them in ab_results.md rather than tuning the stand-in; `final_save.json` is the raw state (no `state` wrapper) and is UTF-8; `run.mjs --hours` and `summary` hours are clock hours (36,000 ticks), planet-hours (250 ticks) are the construction and day-cycle unit.
