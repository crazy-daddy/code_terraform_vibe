## Where phase 7 left things

- Power `trim` (`standins.mjs` `#trimPass`) rates each running turbine or oil generator by `data.power_output / data.throttle` (max seen over the warm-up; throttle ≥ 0.01 and output > 0, else unrated) and keeps, per subnet, the unrated and `keep` generators plus the highest-rated until the kept rating reaches `peak × margin` (at least `keepMin` rated ones); the rest stop. Phase 5's `generated / n` measured demand (the scripts throttle to it), which is why no sample save ever trimmed. Worker facts (read 2026-10-14): turbine `cne()` outputs `min(throttle × 90, steam) × 1.2 / dt × tierFactor`; the oil branch of `PowerSystem.tick` outputs `config.power.oilGeneratorMaxOutputW × throttle(oil-limited) × siteFactor`. `summary.standins.trim.rated[subnet] = {total, kept}` (W); the trim line prints `rated ... (N pinned)`.
- Power `topup` takes `subnets` (null = all; `subnet_0+subnet_1` on the command line, an array in a scenario file). Validation (`topupSubnets()`) runs in the constructor before the archive seeds and any group's setup, so an unknown or empty list throws with no side effect. `summary.standins.topup.subnets` is the list or null.
- A/B: `trim` on 1220 (`20261008_7e5e168/saves/1220_t1809758.json.gz`) stops 4 turbines and keeps the 8 oil generators; the day's load (6.7 kW) exceeds the warm-up peak (4.1 kW), the trimmed grid caps at 6,572 W, the bank drains 5.3 kWh more, no brownout in 0.33 h, atmosphere identical. `topup,subnets=subnet_0` on 0142 reproduces the full-planet heat gain (+4.6 %) with the home bank cycling real: the phase 6 boundary was Outpost 1's grid alone.
- Tests: `test/standins.test.mjs` +3 (highest-rated first; zero demand with unrated, kept and keepMin; topup subnets in string, plus-joined and array form, the throw before side effects, the empty list); 52 green with `node --test "devtools/simulation/headless/test/*.test.mjs"`.
- Docs: `standins.md` (`trim` and `topup` rows, phase table row 7, design notes "Power `trim` rating" and "Construction placement without a builder"), `scenarios.md` (summary fields), `ab_results.md` "Phase 7". TODO's headless block has the phase 7 line.
- Construction placement without a builder (phase 7 handoff item 2) is not done and recorded as a design note: the worker registers no blueprint command (`inventory.*`, `machine.*`, `shop.buy` only); a job turns `active` inside the builder's own construction command (script API), which also consumes the kit. A harness placement would be a state write copying that command or a Python snippet in a script slot.
- Outputs in `out/ab7_*` (never commit `out/`).

## Open (optional)

1. `trim` is one-shot: a warm-up that misses the day's peak under-keeps for the rest of the run (1220: 6.7 kW day load against a 4.1 kW warm-up peak). A re-evaluation every `warmupTicks` that restarts stopped generators when the bank falls (`script.start` on the stopped slots, ghosts recounted) would make it safe for long runs; today, set `warmupTicks` to cover a peak or use `topup`.
2. Placement without a builder, as above, if a logistics-off target ever needs blueprints built.
3. The 0142 shed lines (`[POWER] Night eval ... shed`) named in phase 6 do not appear in the `ab7_*` console logs; phase 6 read them with another log level. Record the `--log-levels` used next time a row cites them.

Pitfalls that still apply: `pass(t)` counts from the run's start, archive ages use `state.tickCount`; `--only-scripts` pins `keep` and a stand-in skips kept slots; validate params for value before any side effect (the constructor, not `#setup`, for anything that must precede the archive seeds); the watcher does not cover `devtools/`; a group that is off or stood in has a boundary (`GROUPS[g].produces` / `consumes`) and the A/B gaps come from there first, name them in ab_results.md rather than tuning the stand-in; `final_save.json` is the raw state (no `state` wrapper) and is UTF-8; `run.mjs --hours` and `summary` hours are clock hours (36,000 ticks), planet-hours (250 ticks) are the construction and day-cycle unit; a generator's `generated` share is demand, not capacity.
