# Database: recipes_smelter

> **Category:** Recipes | **Section:** Smelter Recipes

The Smelter refines raw ore into stock: one ore in, one refined unit out. Select a blueprint with `smelter.set_recipe` and keep the input buffer fed. Every blueprint is listed here from day one, unlocked or not.
