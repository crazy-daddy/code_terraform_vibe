# Guide: expanding_production

## Expanding Production

After the first outpost, progression depends on both expansion and upgrades. Mk II machines improve output, but they do not replace geography. New outposts let you multiply production by building more machines in more places.

### Expansion pattern

- Add an outpost when the home footprint is crowded or travel is wasting time.
- Bring power first, then the terraforming machines for that site.
- Keep each site understandable: a few machines, clear storage, clear script responsibility.
- Upgrade machines when the research lands, but expect more outposts to carry the next phase in a reasonable time.

### What to watch

With one outpost, later phases usually run slowly. Add outposts when travel time, footprint space, or local power becomes the bottleneck. If progress jumps too far from one machine-tier swap alone, that is economy tuning feedback worth reporting.
