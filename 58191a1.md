## 2. Editor conflicts between game and outside editor (sync tool)

Changelog: typing in game is no longer taken as an outside edit; a real two-sided change now
opens a conflict bar (keep one, use the other, merge). In the simworker:

- New `script.getConflict` / `script.openConflict` commands and a `scriptConflictChanged` event;
  `script.preserveConflictPair` is gone.
- `script.setSource` now refuses with `status: changed` while a conflict is open on that script.
- Library writes skip a Library with an open conflict (`ow`), and `iX` no longer counts external
  or conflict drafts as unsaved in-game edits.

`devtools/scripts_sync.py` uses none of the removed commands. The main bundle's handlers for
`run`, `create-library`, `apply-library` and `apply-all-libraries` are unchanged apart from
minifier renames.

## Changelog (v0.1.32)

> Experimental v0.1.32
>
> Saves stay compatible with v0.1.31: each version opens the other's saves.
> Moving rovers, drones, storms and scans slow the Planet Map and the menus far less, most of all on Linux, and a building under construction no longer makes the map redraw every pipe and wire.
> A separate Library editor no longer reloads over and over while you type in a large Library.
> Your own typing is no longer mistaken for an edit from an outside editor, so the game no longer fills a Library's Variants with "In-game edit" copies; copies already made this way are packed away inside the save, which makes the save much smaller.
> When a script really was changed both in the game and in an outside editor, the editor now shows both versions and lets you keep one, use the other, or merge them.
> Selected text in the editor stays selected when the file changes in an outside editor, and selected text in the console stays selected when its line repeats.
> A script can no longer add its own names to a machine or replace a machine's methods, as the editor already warned: keep your own values in your own class, as DOCS shows.
> On Linux, the graphics settings now describe what each choice allows instead of promising a faster mode.
