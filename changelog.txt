Experimental v0.1.25

The Code Lab has a Concepts half: 49 short reading modules with runnable examples.
The first eight lessons now start from a worked shape, not a blank page.
Two new Code Lab achievements mark your first lesson and the halfway point.
The editor, console and DOCS open as separate windows, with a Return to game control.
A pop-out window now appears immediately instead of after ten seconds.
Separate windows remember where you put them, and all come back with Reset Layout.
Your scripts can define custom exception classes, and catch them like any built-in.
New built-in modules: json, heapq and traceback, plus more of functools and dataclasses.
Scripts can deploy, undeploy, decommission and rename hardware through the Ship Computer.
Custom Panels gain text fields, dropdowns, lists, radio groups, and mouse and keyboard input.
Fixed a save with a large external scripts folder never finishing its load.
Saving a file in an external editor no longer freezes the game for seconds.
The Harvesting field is about six times smoother and no longer stutters while it animates.
Autosaving no longer stalls the simulation on a large colony.
Background saves can now be set to every 30 seconds, 1, 2 or 5 minutes.
External script editing can be turned off again, and the Settings section now says whether it is on.
The game no longer creates a scripts folder for players who never asked for external editing.
Fixed an in-game edit being discarded when the scripts folder had not been read yet.
Fixed an outside edit replacing work you were still typing in the in-game editor.
The scripts folder no longer collects recovery files that nothing ever removed.
Faster editor analysis, including the freeze after several renames of one name.
Fixed external editors marking every attribute of self missing behind an unresolved base.
Fixed a bug that could block every save route at once, including exit.
A failed save now names its cause: a full disk, another program holding the file, a second copy.
Failed saves and failed loads can be reported in one click from the pause menu.
Export Save and the DOCS exports now open a real Save As dialog.
The DOCS manual export offers a light or dark appearance and an optional build stamp.
Windows: fixed the game getting slower the longer a session ran, with input and scrolling falling behind.
Windows: fixed the scripts folder rescanning itself for the rest of the session.
Windows: the game recovers from a renderer crash and returns you to your save.
Windows: repeated renderer crashes switch to software drawing, with a setting to choose.
Windows: fixed the picture freezing after Alt+Tab while sound and clicks kept working.
Linux: fixed DOCS PDF export, which failed outright or tried to print to paper.
Linux: a Frame pacing setting for high refresh rate displays, where dragging stepped.
Linux: an Audio device wake-up setting for USB headsets that stayed silent from launch.
Linux: the Steam overlay and screenshot keys now work.
Fixed a plot keeping a machine's dimming after the machine was replaced by a plant or cleared.
Fixed the wildlife reading dropping to zero when a Habitat was undeployed.
The scanner now documents that a sweep can succeed while leaving a contact unidentified.
The drill and sonar descriptions now state that each tier cuts everything below its hardness limit, and name the minerals each one adds.
Notification duration is now a setting.
