## 2. Changelog and docs: no script impact

Checked against `scripts/` and `autoplay/`:

- **Fuel Rods last their full rated life** (Mk IV 240 h, Reactor 72 h at heat 1.0). The worker
  no longer rounds `rodFuel` to 6 decimals each tick (Reactor and the Mk IV generators), so the
  rod no longer drains early. `reactor.ROD_LIFE_GH = 72.0` and the "Mk IV 0.1 rod/day" sizing
  in [production_logistics.md](docs/cheatsheet/production_logistics.md) already state the
  rated life. Rod reserves now last slightly longer than estimated, which is the safe side.
- **Reactor core reaches its target temperature.** The worker no longer rounds `coreTemp`
  (and `water_in_level`) each tick, which stalled the exponential approach a few degrees
  short. `lib/reactor.py` models that exponential approach (`steady_state()`, `LAG_PER_GH`)
  and holds `TARGET_C = FULL_OUTPUT_C` (900 °C). The model now fits the game better. The
  reactor constants are unchanged (no number changes in the simworker diff). The core now
  really reaches 900 °C instead of stopping short; `TRIP_C` (905 °C) still leaves margin.
- **Library fix and apply restarts the scripts its error stopped** (`library.applySource`
  returns `recoveredScriptIds`; scripts now record `errorSourceId`). `scripts_sync.py`
  `recover_scripts()` restarts only scripts still in `error`, so a script the game already
  restarted is skipped. No double restart.
- **Bio Lab `self.specimen`** shows `fragment_id`, `name`, `rarity`, `recipe` for a
  `collected` specimen whose fragment is already cataloged (Bio Collector cargo uses the same
  rule). `extract()` still needs `analyze()`. `lib/bio.py` and `0_cold_boot/bio/bio_lab.py`
  branch on `specimen.stage` and read the fields only after `analyzed`, so nothing breaks.
  Possible later use: a collected specimen of a fragment we don't need can be identified
  before the lab spends time on `analyze()`.
- Recipe name `craft_rubber` shows "Cobalt Ingot + Oil → Rubber + Tar". The id is unchanged.
- UI only: new languages, live `set_status` text in the Scripts tab, Power page folding,
  script tab names, code fonts, Settings width, Windows minimized fix, Greek labels, Linux XIM.
- `docs/database/` recipe and research diffs that flip `*(Unlocked)*` to
  `*(Not yet unlocked)*` come from the save the manual was exported from.
- The `code-terraform` MCP submodule's `Code-Terraform-DOCS-Manual.md` still has the old
  Mk IV numbers (500×/515×). It is updated with the submodule, not here.
